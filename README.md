## 👨‍💻 Projects
- **[Stock Movement Predictor](https://github.com/saurav84rana/Stock-Movement-Predictor)**: A leak free ML pipeline on 24 US stocks, featuring walk forward validation with a purge gap and a held out 2025 test set, also including FastAPI + Docker. The models didn't beat the baseline, and I included write ups explaining why.

- **[Decision Tree in C++](https://github.com/saurav84rana/Decision-Tree)**: A decision tree (best first) and random forest from scratch, featuring polymorphic nodes, min heap growth, and missing value routing.

- **[EDA on CPU Benchmarks](https://github.com/saurav84rana/EDA-on-CPU-benchmarks)**: Exploratory data analysis on 3,825 CPU benchmarks, including data cleaning, PCA, and K-Means clustering.
